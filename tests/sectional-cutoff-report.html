Sectional cut-off reportQualification by section cut-offs, for any company's mock test
What the sheet needs
  • One row per student with a Name column. Member Id, Email and a Groups / Batch column are used when present.
  • One column per section with its maximum marks in brackets, for example Coding (20M), Aptitude (30) or Verbal (15 Marks). Total columns are ignored; the total is added up from the sections.
  • A Status column (Completed / Submitted) marks who attempted. Without it, any student with section scores counts as attempted.
  • For growth view, name files with the test number, e.g. Test-01.xlsx, Test-02.xlsx, so they are compared in order.
